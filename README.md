# Front-End Course — Day 1
 
React + TypeScript + Vite project covering the first day of exercises.
 
## What's Inside
 
- **Counter App** (`src/App.tsx`) — a simple React component using `useState` to increment and reset a count
- **JS Assignment** (`src/assign1.js`) — refactoring exercises: replacing `var` with `const`, template literals, and `Array.map()` with arrow functions
- **TS Assignment** (`src/day-1/assign1.ts`) — same concepts applied with TypeScript
## Tech Stack
 
| Tool | Purpose |
|------|---------|
| React 19 | UI library |
| TypeScript | Type safety |
| Vite | Dev server & bundler |
| ESLint | Linting |
 
## Getting Started
 
```bash
npm install
npm run dev
```
 
Open [http://localhost:5173](http://localhost:5173) in your browser.
 
## Key Concepts Practiced
 
- `const` vs `var` scoping
- Template literals
- Arrow functions
- `Array.map()` for transformations
- React functional components
- `useState` hook
